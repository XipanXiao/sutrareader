# 阅藏 Privacy Policy

Last updated: 2026-05-31

阅藏 is designed as a private reading app.

## Data Collection

This build does not collect personal data.

The app does not require account creation, does not include analytics, does not include advertising, does not track users, and does not send reading progress or bookmarks to a developer-operated server.

## Local Data

The app stores reading progress, bookmarks, completion anchors, and downloaded text cache locally on the device so you can continue reading later and read previously opened works without a network connection.

Deleting the app may delete this local data.

## Network Use

When you open a CBETA work that is not already cached, the app downloads the public CBETA XML text file for that work. These requests are used only to retrieve the text selected by the user.

## Third-Party Services

Text source: CBETA XML P5. Please keep CBETA attribution and source availability notes with redistributed text.
