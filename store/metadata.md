## Description

Sutra Reader helps you read Buddhist sutras over long periods of time. Browse the CBETA library, download texts for offline reading, start from any point, and mark exactly where you stop. The home screen shows progress as a field of dots so you can see what you have read and jump back into the sutra sea.

Current features:

- Searchable CBETA library catalog.
- On-demand sutra download and offline cache.
- Simplified Chinese reading display.
- Comfortable mobile reader.
- Precise bookmarks for arbitrary in-page positions.
- Start / Mark Here progress tracking.
- Dot-map and outline progress views.

Text source: CBETA XML P5. This app should be distributed as a free, non-commercial reader unless CBETA licensing is reviewed and additional permission is obtained.

## Review Notes

The app downloads Buddhist text XML from the public CBETA XML P5 GitHub repository and caches downloaded works locally for offline reading. User progress is stored locally in this build. The app does not sell, modify, or repackage CBETA texts as paid content.

## Privacy

This build does not require account creation and does not collect personal data on an external server. Reading progress and bookmarks are stored on the device.
