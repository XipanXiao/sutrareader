# Version 0.1.0 Release Notes

First TestFlight/App Store candidate.

- Search the CBETA catalog.
- Open and cache sutra texts for offline reading.
- Read in simplified Chinese.
- Save precise reading positions with `记到此处`.
- Resume from active bookmarks.
- Track local progress for each work.
- View global reading progress across the full sutra sea.
- Smooth long-work reading for large texts such as 长阿含经.
